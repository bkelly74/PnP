# BRAND STANDARDS MANUAL — THE MATCH DAY CLUB

_Realigned to the live brand (matchdayclub.co.uk) in Session 005, after the site became
reachable. Supersedes the Session 001–004 invented identity (chevron shield, neutral palette).
The reconstructed mark is faithful to the live raster; replace with the owner's master vector when supplied._

## 1. Brand Position
**The Match Day Club** is a **monthly subscription box for young footballers (ages 12–17)** —
premium gear, real nutrition and recovery essentials, curated by players. Tagline:
**"Elevate your game. Every month."** Built by players, for players; transparent on value
(every item's retail price listed); reassuring for the bill-paying parent (no stimulants,
no lock-in, age-appropriate). Energetic and youth-athletic — gamified with streaks, badges and levels.

## 2. Name & Identity System
- **Name:** *The Match Day Club* (three words). Stylised lockup: `THE` (green) · `MATCH DAY` (large) · `CLUB`.
- **Corporate Logo** — shield mark + wordmark, horizontal lockup (`MDC_Corporate_Logo.svg`).
- **Product / Primary mark** — the shield alone (`MDC_Shield_Master.svg`, `MDC_Product_Identity.svg`).
- **One-colour mark** — single-ink build for embroidery/knit/silicone/small sizes (`MDC_Performance_Mark.svg`).

## 3. The Shield
A **double-keyline angular shield** (flat top, vertical shoulders, point at the base) holding a
**hollow outlined "M" monogram**, with a **green down-chevron** in the top notch and a **green
vertical accent stroke** down the centre. White/Ink on the brand near-black; green is the signal.
- Built on the 1000-unit grid (DR-010), symmetric about x=500.
- Monogram hollows are true transparency, so the mark drops onto any ground.

### Clear space
Clear space on all sides = **X**, where **X = the height of the green down-chevron** in the mark.
Nothing intrudes. Clear space scales with the mark — measure X from the mark in use.
Diagram: `01_Brand/Usage/MDC_Clearspace.svg`.

### Minimum size
- Digital: shield not below **24px** tall.
- Print / embroidery: not below **25mm** tall (re-check stitch density; the one-colour mark is for small/again-st-thread use).
Diagram: `01_Brand/Usage/MDC_Minimum_Size.svg`.

## 4. Colour
Dark-led, near-black ground with one bright lime signal green. Full system:
`01_Brand/Color/MDC_Color_System.md`. Ground `#0A0B0D`, Ink `#F5F7F8`, Green `#8BC63F`.
Green is a signal (accents, CTAs, the mark's stroke) — never a large fill.

## 5. Typography
**Anton** (display / wordmark) + **Archivo** (body/UI) — both SIL OFL. See
`01_Brand/Typography/MDC_Typography.md`. The wordmark lockup is editable Anton/Archivo text in
`MDC_Wordmark.svg` / `MDC_Corporate_Logo.svg`; **outline to vector for production**.

## 6. Misuse
The mark is never:
1. **Stretched** — aspect ratio stays locked.
2. **Rotated** — the shield always sits upright.
3. **Recoloured** outside the system — Ink / Green only on the brand ground.
4. **Shadowed** — no drop shadows or glows (the green's subtle bevel is the only depth, and it's part of the mark).
5. **Outlined** — no added strokes or keylines (the keyline is already the shield).
6. **Low-contrast** — keep clear figure/ground; never tone-on-tone.

Diagram: `01_Brand/Usage/MDC_Misuse.svg`. Full usage rules: `01_Brand/Usage/MDC_Usage.md`.
