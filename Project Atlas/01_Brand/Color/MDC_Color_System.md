# COLOUR SYSTEM — MATCHDAY CLUB®

Neutral-led, premium, monochrome-first (DR-006). One restrained heritage accent, used sparingly.

## Core
| Name | HEX | RGB | Use |
|------|-----|-----|-----|
| Atlas Black | `#0E0E0E` | 14, 14, 14 | Primary. Shield, type, packaging. |
| Bone | `#ECE8E1` | 236, 232, 225 | Reverse/ground. Negative space in the mark. |
| Graphite | `#2A2A2A` | 42, 42, 42 | Secondary surfaces, UI depth. |

## Accent (sparing)
| Name | HEX | RGB | Use |
|------|-----|-----|-----|
| Pitch | `#14342B` | 20, 52, 43 | Heritage accent only. Never dominant. |

## Rules
- Default to mono. Accent appears on <10% of any composition.
- No gradients. No clichés. Less ink.
- Pantone/thread cross-reference to be added in the Supplier Pack (M2).
