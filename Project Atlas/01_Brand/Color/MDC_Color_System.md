# COLOUR SYSTEM — THE MATCH DAY CLUB

Observed from the live site (matchdayclub.co.uk), 2026-06-27. Dark-led, near-black ground
with a single bright lime-green signal colour. Supersedes the earlier invented "neutral +
Pitch" system (DR-006 superseded by DR-013).

## Core
| Name | HEX | Use |
|------|-----|-----|
| Ground | `#0A0B0D` | Primary background (site `theme-color`). |
| Ground 2 | `#0E1013` | Secondary background band. |
| Ink | `#F5F7F8` | Primary text and the logo mark on dark. |
| Muted | `#9AA1AA` | Secondary text. |
| Muted 2 | `#7D848E` | Tertiary text, captions. |

## Surfaces
| Name | HEX | Use |
|------|-----|-----|
| Surface | `#15181C` | Cards. |
| Surface 2 | `#1B1F25` | Raised cards. |
| Surface 3 | `#23282F` | Highest elevation / borders. |
| Line | `rgba(255,255,255,.09)` | Hairline dividers. |
| Line strong | `rgba(255,255,255,.16)` | Emphasised dividers. |

## Signal — Green
| Name | HEX | Use |
|------|-----|-----|
| Green | `#8BC63F` | The brand signal. Logo accent, CTAs, highlights. |
| Green bright | `#A6E24A` | Hover / emphasis. |
| Green deep | `#6AA62E` | Pressed / shadowed green (e.g. "THE" on light). |
| Green glow | `rgba(139,198,63,.38)` | Focus glow only. |

## Rules
- Dark is the default ground; the brand lives on near-black, not white.
- Green is a **signal**, not a fill — accents, CTAs and the logo stroke, not large areas.
- No gradients on the mark; the green accent stroke carries a subtle two-tone **bevel**
  (bright `#8BC63F` + deep `#6AA62E`) — this is the only depth in the mark.
