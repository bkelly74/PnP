# LOGO USAGE — THE MATCH DAY CLUB

Production usage rules for the shield mark. Diagrams in this folder are the authoritative
geometry; the Brand Standards Manual references them.

## Clear space — `MDC_Clearspace.svg`
- Minimum clear space on **all four sides** = **X**, where **X = the height of the green
  down-chevron** in the mark.
- Nothing — type, rule, image edge, another mark — may enter the keep-out zone.
- Clear space scales with the mark: measure X from the mark in use, never a fixed pixel value.

## Minimum size — `MDC_Minimum_Size.svg`
Applies to the shield mark; the corporate lockup is governed by wordmark legibility and sits larger.

| Medium | Floor (shield height) | Note |
|--------|----------------------|------|
| Digital | **24px** | Below this the monogram hollows close up. |
| Print / embroidery | **25mm** | Use the one-colour mark; re-check stitch density (Supplier Pack, M2). |

Preferred use is above the floor with breathing room — the floors are limits, not targets.

## Misuse — `MDC_Misuse.svg`
The mark is never:
1. **Stretched** — aspect ratio stays locked.
2. **Rotated** — it always sits upright.
3. **Recoloured** outside the system — Ink and Green only.
4. **Shadowed** — no drop shadows or glows.
5. **Outlined** — no added strokes or keylines (the keyline is already the shield).
6. **Low-contrast** — keep clear figure/ground separation; never place tone-on-tone.
